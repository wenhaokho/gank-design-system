# EmptyState

Centred in the space the content would fill: a 40px `bg-control` disc with an outlined glyph (document, chart, clock), one line in `ink-muted` saying what is missing ('Tidak ada data untuk ditampilkan', 'Belum ada postingan yang dijadwalkan'), and, when there is a way to fill it, a heading plus a default button ('Kamu belum memiliki membership apa pun.' → '+ Tingkatan membership'). Marketing-style empty states (Keanggotaan) add an illustration above the heading.

Consumer provides: the message in the user's words and, if one exists, the action.
