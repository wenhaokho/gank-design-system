# ListingCard

A shop item on the public profile's Toko tab and in the dashboard's Toko list: square media on top (with a 'Tidak Aktif' dot status over the corner when unpublished), then title in `label`, a type pill ('• Commission', 'Digital Goods'), the price in USD with the local conversion in `caption` below ('US$ 2.00 / Rp 38.063'), and for the owner an edit pencil and ⋯ menu. Cards are 240px wide in a wrapping grid with 16px gaps.

Consumer provides: media, title, type, USD price and local price, active state, and whether the viewer owns it.
