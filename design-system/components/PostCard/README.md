# PostCard

A feed post: 36px avatar, author name in `label` weight with the verified check, relative time in `caption`, then the post title (18/600) and a 'Lihat terjemahan' link, media edge to edge, an action row (heart, comment, share, ⋯) above a hairline, and a footer line. A **locked** post blurs or replaces the media with a gradient, shows a media count chip ('🖼 2 🎥 1') and a cta button ('Buka post' / 'Berlangganan untuk Membuka'); its footer says why commenting is closed ('Untuk mengomentari postingan ini, Anda harus berlangganan'). Posts stack with 16px gaps in a 648px column.

Consumer provides: author, time, title, media or the locked state with its unlock action, like count.
