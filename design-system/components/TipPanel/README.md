# TipPanel

The 'Dukung Saya' card on a creator's public profile, in the profile theme. A heading, a currency select joined to an amount input, three preset amount buttons in a row (Rp 20.000 · Rp 100.000 · Rp 200.000), the full-width **cta** 'Tip' button, and the one-line note 'Semua tip diberikan langsung ke kreator dan tidak dapat dikembalikan.' On the creator's own profile this card is replaced by 'Buat goal disini!' with 'Buat Goal Baru' (secondary) and 'Lihat Halaman Tip' (cta).

Consumer provides: the creator's currency and preset amounts; the note is fixed copy.
