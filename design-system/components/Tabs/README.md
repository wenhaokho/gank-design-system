# Tabs

An underlined strip at the top of a panel that switches the panel's content ('Daftar Terjual / Daftar Terbeli / Unduhan', the five Stream tabs). Active tab is `ink` with a 2px `ink` underline; inactive tabs are `ink-muted`; the strip's baseline is a 1px `line`. A new tab can carry the red **Baru** tag. Tabs change the URL (`/manage/my-orders/sold`) so each is linkable.

Consumer provides: 2–6 short noun labels and `aria-selected` on the current one.
