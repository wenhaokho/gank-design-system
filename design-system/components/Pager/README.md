# Pager

Below every table and list: ‹ 1 2 3 4 5 … 11 › with the current page on a `bg-control` square, and on the right a small select with 'Hasil per halaman' (10 / 25 / 50). Arrows disable at the ends in `ink-faint`. Lists that load in place use a full-width default button 'Muat lebih banyak' instead (wallet history).

Consumer provides: current page, page count, page size.
