# Segmented

Two pill forms for picking one of a few options. The **segmented control** is a bordered pill with the chosen option filled `bg-hover` ('Pesan Langsung / Siaran', 'Vertikal / Horizontal', '3 baris / 5 baris / 10 baris'). **Chips** are loose pills in a row used as filters ('Subscribers · Supporter · Pengikut (3) · Pengguna Yang Diblokir'); the chosen chip is `bg-hover` and semibold. Neither uses `brand`.

Consumer provides: 2–5 options and `aria-pressed` on the chosen one.
