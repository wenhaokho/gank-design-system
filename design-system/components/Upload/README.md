# Upload

A dashed dropzone (`ink-faint` 1px dash, `bg-inset`, `radius-md`) with an outlined 'Unggah Media' button and a one-line constraint in `caption` ('Pilih hingga 10 gambar dan 1 video, dengan rasio 4:3', 'Video apa saja hingga 20MB', 'Semua JPG, JPEG, PNG, MP4, atau GIF sampai 300 MB'). Post editors add 'atau' and a 'URL Youtube atau Vimeo' link below. Uploaded images appear as 120px thumbnails with a × badge; the chosen cover gets a `brand` border.

Consumer provides: the button label, the constraint line, and the accepted types.
