# Button

Pill-shaped, 44px tall, semibold. The light **cta** fill is the main action of a panel ('Simpan Perubahan', 'Tarik Uang', 'Publish Listing') and appears once per panel; the grey default (`bg-control`) is for everything else ('Tambah gold', 'Muat lebih banyak', 'Refresh Overlays'); **brand** red fill is reserved for upgrade/plan buttons; **ghost** (outline) for toolbar actions beside a title. Verb first, sentence case, no trailing punctuation.

Consumer provides: the label, `disabled` when the action cannot run, `gk-btn-block` when it spans a form.
