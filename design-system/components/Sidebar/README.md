# Sidebar

The fixed 280px dashboard navigation on `bg-sidebar`. Top: the red wordmark and the notification bell. Items are 48px rows with a 24px outlined icon and a 17px label; groups ('Keuangan', 'Pengaturan') expand to 40px child rows indented under the icon. The current page is `bg-hover` with a 3px `brand` bar on the left edge. A hairline and the 'Pusat Kreator' eyebrow separate fan-side items (Feed, Jelajahi, Pesan, Keuangan, Pengaturan, Mengikuti) from creator-side ones (Dasbor, Pengaturan Kreator, Sumber Daya). The 'Tingkatkan ke Boost' card is pinned at the bottom with a cta button. On public pages the sidebar collapses to a 60px icon rail.

Consumer provides: the item list with `aria-current="page"` on one item; omit the upgrade card for Boost subscribers.
