# Alert

An in-panel band, `radius-md`, that explains something about the page. **Neutral** (`bg-control`) carries a hint with an inline link and a dismiss × ('Jika Anda ingin pelanggan melihat harga total yang sama saat checkout… di sini'). **Info** (`info` blue, white text) is a nudge with a dark action button ('💡 Buat target tip sekarang… — Buat Target'). Alerts sit directly under the tab strip or the title, full width of the panel, and never stack more than one.

Consumer provides: one sentence, an optional link or action label, and whether it can be dismissed.
