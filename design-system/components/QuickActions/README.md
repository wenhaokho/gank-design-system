# QuickActions

The row of 56px tiles on the dashboard banner under 'Akses cepat ke semua cara kamu bisa dapat penghasilan': Postingan ✏️, Keanggotaan 👑, Listing 👜, Tip 🪙, Peringatan Streaming 📺. Tiles are translucent white on the banner image (`#ffffff14` fill, `#ffffff22` border, `radius-md`) with the emoji centred and a 12px label below, 64px wide, 24px apart. This is the only place the product uses emoji as icons.

Consumer provides: up to five actions, each with an emoji and a one- or two-word label.
