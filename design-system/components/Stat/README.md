# Stat

Dashboard summary numbers and wallet balances. A **stat** is a coloured 28px disc icon, the value in `stat` (20/600, tabular) and the unit in `body` at `ink-muted` ('0.00 USD Pendapatan', '1 Tayangan'); three sit in a row separated by hairlines. A **balance** is the value alone in `balance` (32/600) centred in an inset well ('108 🪙', 'US$ 0.00') with its action button directly below.

Consumer provides: a formatted value (currency symbol or coin), the unit word, and for stats the icon tone (green money, purple supporters, blue views).
