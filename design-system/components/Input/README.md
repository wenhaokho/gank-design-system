# Input

Text inputs, selects and textareas share one shape: `bg-control` fill, `radius-md`, 44px tall, 16px side padding, no border at rest and a 2px `brand` ring on focus. The label sits above in `label` weight with a 12px gap; helper text in `caption` at `ink-muted` sits below. Selects use the same chevron glyph as filter chips.

Consumer provides: a visible label for every control (placeholders are hints, not labels), helper copy that says why the field matters, and an `id` so the label is associated.
