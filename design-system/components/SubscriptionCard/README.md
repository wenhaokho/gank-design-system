# SubscriptionCard

One membership the user holds (Langganan page). A `bg-hover` header strip carries the creator's avatar, name with check, an outlined 'Obrolan' button and the status on the right (dot + 'EXPIRED' / 'AKTIF'). The body shows the tier thumbnail (120×80) and tier name (18/600 with the crown emoji when the tier has one), then four facts as a definition grid whose labels are in `info` blue: Status Perpanjangan · Periode Langganan · Tanggal Pembayaran Terakhir · Harga. The footer holds one default button ('Berlangganan Ulang') or a note when the creator disabled memberships.

Consumer provides: creator, tier, status, the four facts, and the footer action or note.
