# ProfileHeader

The 60px bar at the top of every public page, always on `bg-sidebar` whatever the profile theme: the creator's 36px avatar and name with check on the left, centred tabs (Profil · Feed · Toko · Membership · Commission; the active one underlined in ink) and on the right the one action: 'Sesuaikan Halaman' for the owner, 'Dukung Saya ♡' for a visitor. It sits beside the 60px icon rail, above the banner image.

Consumer provides: creator name and avatar, the tabs the creator has enabled, which is current, and the owner/visitor action.
